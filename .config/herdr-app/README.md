# Herdr app config (only the hand-made files)

The rest of `~/.config/herdr-app` is the app's own (runtime state, generated `AGENTS.md`, `*.d.ts`,
shipped mods) or generated by the `theme` script (`themes/ghostty.json`); install.sh pre-creates the
folders so stow links single files.

- `keys.json`: ctrl-s opens the `prefix` mod; cmd-a sends ctrl-x tab (as Ghostty).
- `settings.json`: theme `ghostty` (written by `theme`, follows the herdr Ghostty theme).
- `layouts/main-copy.json`: the shown layout (clone of `main`); sidebar blocks use `radar-spaces`, `radar`.
- `mods/prefix`: tmux-like prefix popup.
- `mods/radar`, `mods/radar-spaces`: copies of the shipped `agents` and `spaces` mods
  (`cloned_from` in mod.json names the version) with herdr-radar's look.
  After a Herdr update, diff the shipped mods against these copies:
  `diff ~/.config/herdr-app/mods/agents/main.js ~/.config/herdr-app/mods/radar/main.js`
  (`spaces` against `radar-spaces`) and carry over upstream fixes.

Check a mod after editing: `herdr-app check ~/.config/herdr-app/mods/<name>`.
